# SmartThings (via Matter)

ThermalTrace does **not** ship a SmartThings Cloud-to-Cloud connector.

Use the [Matterbridge plugin](https://github.com/doodersrage/thermaltrace-matter) so SmartThings can add garage temperature, humidity, leak, door, power, and motion over Matter on your LAN — the same path as Apple Home and Google Home.

- Product: [thermaltrace.dev/integrations/smartthings](https://thermaltrace.dev/integrations/smartthings)
- Matter install: [thermaltrace.dev/integrations/matter](https://thermaltrace.dev/integrations/matter)
- Positioning vs consumer pods: [thermaltrace.dev/compare/govee](https://thermaltrace.dev/compare/govee)
